# 企业流水风险监测平台

轻量化企业流水风险监测平台交互原型，包含运营端与银行机构端演示页面。

## 本地运行

本项目为纯静态网页，无需安装依赖。使用任意静态文件服务器打开项目根目录即可。

## V1 2026-09 功能更新

- 总览累计及趋势按结果户次统计；事件提示按组织机构代码去重；异常提示按名单记录计数。
- 北京时间为全站时间口径。贷中在页面打开时检查并补执行到期模拟任务，网页关闭期间不会运行服务器任务。
- 企业组成保存在导入名单中；每次成功查询和每月贷中批次保存独立结果快照，历史下载读取对应快照。
- 浏览器 IndexedDB（risk-monitor-v1）保存名单、结果、额度流水、账号设置及已读状态。同一浏览器刷新可保留；不同设备、不同浏览器及不同网站地址不共享；清除站点数据会删除本地记录。
- 贷前明细保留最近六个自然月（含本月），更早数据仅保留累计统计汇总；贷中快照长期保留。
- 名单支持 XLSX / UTF-8 CSV，默认模板为 XLSX。列为企业名称、组织机构代码、机构编码（编码长度9/14）。前导零仅按可靠原值或明确零填充格式读取，不猜测修复。错误名单整体拒绝，可下载错误清单。
- 首次成功查询扣5币，重复查看不重复扣费；完整结果与扣费通过同一本地数据库事务提交。无限额度账号免扣费。
- 各筛选区最右侧有独立重置入口；额度流水支持组合筛选和导出；通知支持已读回看。

本地账号密码仅为公开的原型演示逻辑，不能作为生产安全认证。不要导入真实敏感企业数据；本版不替代全栈服务，不修改V2或全栈安装包。

## 测试

网页运行不需要构建。开发测试使用 Node.js 24：先执行 `npm install`，再执行 `npm test`。测试覆盖导入边界、时区与月度任务、风险变动、历史导出、扣费去重、银行隔离、组合筛选与本地保存恢复。SheetJS 0.20.3 已固定在 vendor 目录，并附许可证。
